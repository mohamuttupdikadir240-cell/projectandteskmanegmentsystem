ABSTRACT
Effective coordination of projects and tasks remains a persistent challenge for many organizations that still rely on manual methods such as spreadsheets, paper-based logs, and informal messaging to plan, assign, and track work. These methods are prone to miscommunication, lost updates, missed deadlines, and a lack of visibility into who is responsible for what, which ultimately reduces organizational productivity and accountability. This study set out to design and implement a role-based, web-based Project and Task Management System capable of centralizing project planning, task assignment, progress tracking, deadline management, and reporting in a single platform accessible to Administrators, Project Managers, and Team Members.
The study adopted the Agile-oriented Software Development Life Cycle (incremental development) as its research and system development design, combined with a Clean Architecture approach for the system's technical design. Requirements were gathered through review of existing literature and analysis of common organizational project-management practices, and were translated into functional and non-functional requirements, entity-relationship models, and use-case designs. The resulting system was implemented using ASP.NET Core 9 MVC, Entity Framework Core 9, and Microsoft SQL Server, and provides role-scoped dashboards, project and task CRUD operations, team assignment, comments and file attachments, automated deadline notifications, exportable PDF/Excel reports, analytics, audit logging, and global search.
The system was tested using unit and integration tests to verify that each module performs its intended function and that the modules interact correctly end-to-end. The findings show that a centralized, role-based platform can substantially reduce the coordination overhead associated with manual project tracking, improve the traceability of task ownership, and give managers real-time visibility into project and team performance. The study concludes with recommendations for further enhancement of the system, including native mobile access, real-time push notifications, and integration with third-party calendar and communication tools.
Keywords: Project Management, Task Management, Role-Based Access Control, ASP.NET Core, Clean Architecture, Software Development Life Cycle.
